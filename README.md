# TLGO Process Flow Animation

**[▶ Watch the animation](https://quakfoolee-dotcom.github.io/tlgo-process-flow-animation-site/TLGO_Process_Flow_Animation.html)**

Animated 16-step process flow for TLGO (thermally treated layered graphene oxide) batch synthesis, with safety training mode, quizzes, chapters, Present mode and recorded voice-over (2:43).

## Run locally
Open `TLGO_Process_Flow_Animation.html` through a local server (e.g. `npx serve .`). Audio and imports need http, not `file://`.

## Files
- `TLGO_Process_Flow_Animation.html` — main animation
- `go-flow-v2.jsx`, `animations-v3.jsx`, `tweaks-panel.jsx`, `support.js` — runtime
- `music-v3-duck.wav`, `music-v3.wav`, `vo-track.wav` — audio
- `uploads/tlgo-voiceover/` — safety voice clips
- `Voice-over Script.md` / `.csv` — narration script (rev. 3)
- `_ds/` — Industry design system
