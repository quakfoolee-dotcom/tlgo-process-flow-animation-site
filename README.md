# tlgo-process-flow-animation
Animated 16-step process flow for TLGO (thermally treated layered graphene oxide) batch synthesis, with safety training mode, quizzes, chapters, Present mode and recorded voice-over (2:43).

Run
Open TLGO Process Flow.dc.html in a browser via a local server (e.g. npx serve .) — audio and imports need http, not file://.

Or enable GitHub Pages (Settings → Pages → Deploy from branch main, root) and open /TLGO%20Process%20Flow.dc.html.

Files
TLGO Process Flow.dc.html — main animation
go-flow-v2.jsx, animations-v3.jsx, tweaks-panel.jsx, support.js — runtime
music-v3-duck.wav, music-v3.wav, vo-track.wav — audio
